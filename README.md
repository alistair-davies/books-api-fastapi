# books-api-fastapi

A simple book management REST API built with FastAPI, SQLite and Postman.

## Features

- Get all books
- Get a single book by ID
- Add books
- Update books
- Delete books
- Prevent duplicate books from being added
- Return appropriate HTTP status codes

## Technologies

- Python
- FastAPI
- SQLite
- Pydantic
- Postman

## What I Learned

- Building REST APIs with FastAPI
- Working with SQLite databases
- Creating CRUD endpoints
- Using Pydantic for request validation
- Returning JSON responses
- Working with HTTP status codes and exceptions
- Refactoring duplicated code into reusable functions
- Testing APIs with Postman
